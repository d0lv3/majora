# Scene photographs

Drop the generated images here. Nothing else needs editing — `src/sim/story/scenePhotos.js`
globs this folder and matches a file to a scene by its **file name minus the extension**,
so `scene-03-forres-court.png` fills the scene whose `image` is `scene-03-forres-court`.

`.png`, `.jpg`, `.jpeg`, `.webp` and `.avif` all work. A scene whose file is not here yet
plays without a picture rather than breaking, so they can arrive one at a time.
